# Ананасовый улун — тестовое задание Teaboom.ru

Автор: Алексей Курсанов. Дата: 14 октября 2026 года.

Опубликованная страница: https://alexey-portfolio-uk1x.onrender.com/teaboom/

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.
Либо запустите из этой папки `python -m http.server 8080` и откройте http://localhost:8080/.

## Структура

- `index.html` — семантическая разметка карточки.
- `styles.css` — стили и адаптивная сетка, без Bootstrap и шаблонов.
- `product.js` — четыре фасовки и переключение цен/артикула.
- `assets/` — локальные изображения товара, логотипа и фона.

## Реализация

Четыре фасовки: 100, 500, 1000 и 5000 г. При выборе меняются артикул, актуальная и старая цена; выбранное состояние оформлено CSS. Использованы нативные radio-кнопки: доступны Tab и стрелки. Изменения цен озвучиваются через `aria-live`. У кнопки есть состояния наведения, нажатия и клавиатурного фокуса. Нажатие показывает локальное подтверждение, не создавая заказ.

На 1440 и 768 px — две колонки; на 375 px — одна. Изображения хранятся локально, для работы страницы сторонние запросы не нужны. Системный запасной шрифт используется без загрузки внешних библиотек. Без backend, аналитики, оплаты и реальной корзины.

Изображения, название, состав и стилистический образец: https://teaboom.ru/product/ananasovij-ulun. Краткое описание сокращено из описания оригинального товара. Фотография, логотип и фон принадлежат Teaboom.ru; использованы исключительно для тестового задания по разрешению в его условиях. Тестовая страница не является магазином.

Вёрстка выполнена с использованием ИИ-помощника; проверена в браузере.

Логотип, путь категории и название категории — статические элементы оформления, без переходов на настоящий магазин. На странице только одна карточка товара.
